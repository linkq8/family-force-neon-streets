# مصنع أصول الشخصيات — المرحلة 7

المصنع يعمل على **صور ثابتة فقط** ولا يولّد أو يعالج الفيديو. وهو لا يغيّر أصول
اللعبة الحالية. لكل شخصية يلزم Portrait معتمد وCharacter Model Sheet معتمد، ثم
ثماني صور لكل واحدة من الحركات الإحدى عشرة.

يثبت ملف `style_formula.template.json` أسلوب الرسم، الهوية، الملابس، العمر،
النسب، زاوية الكاميرا والألوان طوال الطلب. لا يُغيّر بعد اعتماد النموذج.

## بوابة الجودة

- Atlas نهائي `1536×2112`؛ 8 أعمدة × 11 صفًا؛ كل خلية `192×192`.
- PNG RGBA بخلفية شفافة وAlpha ثنائي لمنع الهالات على Android.
- تثبيت القدم على خط موحد، باستثناء القفز والسقوط.
- رفض الإطار الفارغ أو المقصوص أو الملامس للحافة.
- رفض تكرار الوضعيات أو ضعف اختلاف Silhouette بين الإطارات.
- إنتاج Contact Sheet إلزامي للموافقة البصرية وتقرير JSON قابل للأتمتة.

## سياسة المحاولات والتكلفة

الحد الأقصى ثلاث محاولات صور ثابتة لكل حركة. المحاولة الثانية والثالثة تعيدان
الحركة الفاشلة وحدها مع ذكر عيب QA. لا تعاد صورة أو حركة معتمدة. إذا فشلت
المحاولة الثالثة تتحول إلى تصحيح فني يدوي، فلا توجد إعادة توليد مفتوحة تستهلك
الرصيد أو تغيّر هوية الشخصية.

أداة التنفيذ موثقة في
`android/tools/customer_assets/README.md`. مخرجاتها تبقى في مجلد Staging ولا
تدخل APK إلا بعد نجاح الفحص والموافقة البشرية.
