# توافق وحدات التحكم

طبقة الإدخال تدعم Android TV مع وحدتي تحكم منفصلتين للاعبين P1 وP2، مع إبقاء اللمس ولوحة المفاتيح دون تغيير.

## الوحدات المدعومة

- PlayStation DualSense وDualShock عبر أزرار ومحاور Android القياسية.
- Xbox Wireless Controller وXbox One/Series وXInput عبر التعيين القياسي.
- Nintendo Switch Pro Controller وزوج Joy-Con المدمج عبر التعيين القياسي.
- Joy-Con مفرد وJoy-Con 2 مفرد: تعيين احتياطي للأزرار `BUTTON_1..8` التي تعرضها بعض أجهزة Android TV.
- ريموت Android TV: الأسهم، التأكيد، والرجوع في القوائم.

## DualSense على أجهزة Android TV القديمة

بعض صور Android TV القديمة، ومنها إصدارات موجودة على Xiaomi Stick، قد لا تحتوي
ملف AOSP الاحتياطي الخاص بـDualSense. عندها يخلط النظام بين أزرار الوجه والكتف،
ويتعامل مع العصا اليمنى كمحاور L2/R2 بدل الزنادين الحقيقيين.

تكتشف اللعبة هذا التخطيط من كون نطاق trigger سالبًا/موجبًا بدل `0..1`. وتضيف
نسخ Xiaomi TV/Stick/Box القديمة حالة احتياطية موجهة للمضيف لأن بعضها لا يعلن
النطاق المكسور رغم غياب ملف key-layout. كما تُصحح أحداث DualSense التي يرسلها
الـFirmware كمصدر Keyboard. يطبّق التصحيح تعيين AOSP الرسمي لرموز المسح
`304..317` على PlayStation فقط؛ وتبقى Shield وSony وXbox وNintendo على المسار
القياسي. تصحيح محاور trigger مستقل عن تصحيح الأزرار حتى لا تتضرر إصدارات Xiaomi
الحديثة التي تعرض L2/R2 بصورة صحيحة. يدعم الرمي الآن:

- `L2` كـKeyEvent؛
- `AXIS_LTRIGGER` أو `AXIS_BRAKE` في التخطيط القياسي؛
- محور `Z` المصحح في تخطيط DualSense القديم؛
- ضغط Touchpad كاختصار DualSense احتياطي للرمي.

## التعيين داخل اللعب

| الفعل | تعيين Android القياسي |
|---|---|
| تأكيد / قفز | A |
| رجوع / ركلة | B |
| لكمة | X |
| لكمة ثقيلة | Y |
| Link | L1 |
| Special | R1 |
| رمي السلاح | L2 |
| ركلة ثقيلة | R2 |
| الحركة والقوائم | العصا اليسرى أو D-pad |

تحتفظ أزرار Nintendo المطبوعة باختلاف مواضعها المادي عن Xbox؛ اللعبة تعتمد أحداث Android القياسية، وتضيف فقط تعيينًا احتياطيًا عندما يعرّف النظام Joy-Con المفرد كأزرار عامة.

## بوابة الاختبار

يشغّل `tools/test_customer_release.sh` اختبار `ControllerCompat` قبل أي بناء. يفحص اكتشاف Joy-Con 2 وSwitch Pro وXbox وDualSense، ويضمن أن التعيين القياسي لا يتغير لأجهزة Xbox أو زوج Joy-Con.

يبقى اختبار جهاز حقيقي مطلوبًا لكل طراز تلفاز/إصدار نظام، لأن برنامج Bluetooth الثابت قد يغيّر اسم الجهاز أو أحداث المحاور، خصوصًا في Joy-Con المفرد.
