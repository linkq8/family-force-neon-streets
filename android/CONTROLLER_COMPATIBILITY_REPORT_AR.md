# توافق وحدات التحكم

طبقة الإدخال تدعم Android TV مع وحدتي تحكم منفصلتين للاعبين P1 وP2، مع إبقاء اللمس ولوحة المفاتيح دون تغيير.

## الوحدات المدعومة

- PlayStation DualSense وDualShock عبر أزرار ومحاور Android القياسية.
- Xbox Wireless Controller وXbox One/Series وXInput عبر التعيين القياسي.
- Nintendo Switch Pro Controller وزوج Joy-Con المدمج عبر التعيين القياسي.
- Joy-Con مفرد وJoy-Con 2 مفرد: تعيين احتياطي للأزرار `BUTTON_1..8` التي تعرضها بعض أجهزة Android TV.
- ريموت Android TV: الأسهم، التأكيد، والرجوع في القوائم.

## التعيين داخل اللعب

| الفعل | تعيين Android القياسي |
|---|---|
| تأكيد / قفز | A |
| رجوع / ركلة | B |
| لكمة | X |
| لكمة ثقيلة | Y |
| Link | L1 |
| Special | R1 |
| رمي السلاح | L2 |
| ركلة ثقيلة | R2 |
| الحركة والقوائم | العصا اليسرى أو D-pad |

تحتفظ أزرار Nintendo المطبوعة باختلاف مواضعها المادي عن Xbox؛ اللعبة تعتمد أحداث Android القياسية، وتضيف فقط تعيينًا احتياطيًا عندما يعرّف النظام Joy-Con المفرد كأزرار عامة.

## بوابة الاختبار

يشغّل `tools/test_customer_release.sh` اختبار `ControllerCompat` قبل أي بناء. يفحص اكتشاف Joy-Con 2 وSwitch Pro وXbox وDualSense، ويضمن أن التعيين القياسي لا يتغير لأجهزة Xbox أو زوج Joy-Con.

يبقى اختبار جهاز حقيقي مطلوبًا لكل طراز تلفاز/إصدار نظام، لأن برنامج Bluetooth الثابت قد يغيّر اسم الجهاز أو أحداث المحاور، خصوصًا في Joy-Con المفرد.
