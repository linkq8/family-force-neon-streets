# Essa Redraw V4

إعادة رسم كاملة لشخصية Essa فقط، مبنية بصور ثابتة داخل Codex/ImageGen دون فيديو.

## الأقفال البصرية

- الهوية: شعر متراجع/رأس أصلع، لحية سوداء، نظارة سوداء مستطيلة، وبشرة بنية دافئة.
- العين: قزحية بنية داكنة، بؤبؤ شبه أسود، لمعة بيضاء وبياض عين منفصل عن البشرة.
- الزي: درع أحمر وذهبي مع مفاصل وطبقة داخلية كحلية، دون تغيير التصميم.
- الأسلوب: عناقيد بكسل صغيرة، حد خارجي كحلي حاد، تظليل cel بثلاث درجات،
  وتباين مطابق لمستوى Striker وShield Guard.
- الحركة: لوحة `4×2` لكل حركة، مع ثبات الحجم وخط الأرض في idle/walk.

## الحركات

`idle`, `walk`, `punch`, `kick`, `heavy_punch`, `heavy_kick`, `jump`,
`special`, `link`, `hurt`, `knockdown` — ثمانية إطارات لكل حركة.

## البناء

يستخدم `android/tools/build_two_character_redraw.py` مصدر V4 لـEssa ومصدر V3
لـStriker. يحتفظ مسار Essa بمساحة اللوحة الكاملة بدل قص الجسم وإعادة تكبيره لكل
إطار، ثم يوحّد مقياس الصف وخط الأرض. هذا يمنع ظاهرة التكبير والتصغير أثناء المشي.

لا يغيّر هذا المصدر أي شخصية أخرى.
