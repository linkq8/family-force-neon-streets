# Unity 0.5.2 — إصلاح استئناف الحركة

إصلاح برمجي للحركة مع الاحتفاظ برسوم198 المقبولة دون تغيير. لا يدّعي هذا
الإصدار اكتمال الصقل الفني للوضعيات أو إنتاج12 رسمة جديدة لكل ضربة.

- حفظ موضع دورة المشي عند تلقي ضربة أو تنفيذ حركة، واستئنافها من الموضع نفسه
  بدل الرجوع للإطار الأول. تكرار الضربات لم يعد يحرم النصف الثاني من الدورة.
- حفظ موضع الدورة عند انقطاع اللمس القصير بدل إعادة أول خطوة مرارًا.
- ضبط توقيت اللكمة والركلة، وتنظيف حالة المشغل عند تبديل الشخصية؛ احترام
  إيقاف الزمن، وإيقاف المشي عند حد المرحلة. باقي رسوم الضربات والقفز لم تستبدل.
- عداد للإطارات: F8 أو لمس الشاشة بثلاثة أصابع؛ يتوقف بالاختصار نفسه.
- صفحة المشي الأصلية1536×1152، خلايا384×384، pivot(192,24)، PPU384؛
  بايتات أطلس المشي والقتال مطابقة للإصدار0.5.1. لا تغيير للوجه أو الشعر.
- المحاولات التوليدية الجديدة محفوظة للمراجعة لكنها لم تدخل APK، وكذلك
  تجربة المفاصل التي شوّهت الدرع. لا صور فوتوغرافية شخصية داخل الحزمة.

الاختبارات:33 اختبار أدوات محليًا PASS؛ اختبار لعب Unity رصد12 إطار مشي فعلًا
واختبر الاتجاهين والعودة للوقوف والحركات السابقة. فحص الوجه يقارن الألوان
مع المصدر، ولا يدّعي تحكيمًا بشريًا للشبه أو اكتمال جودة الحركة. اختبار انحدار
مستقل يحاكي الضربات المتكررة وانقطاع اللمس ويفحص الوصول إلى الإطارات12 كلها.
تثبيت وتشغيل APK على محاكي Android34/ARM64 نجح؛ قراءة عداد الإطارات من
فيديو الشاشة رصدت1–12 جميعها، والسجل أثبت11→hurt→11→12 بعد الإصلاح.

Android: ARMv7+ARM64، الحزمة com.familyforce.neonstreets.unityprototype،
versionName0.5.2-essa-motion-fix،versionCode3؛ توقيع Android debug مثل0.5.1.
هذا تحديث لمشروع Unity التجريبي فقط، لا للعبة Android Canvas القديمة.

التسليم يحتفظ بالنسخة السابقة0.5.1؛ لا يدّعي حل جميع عيوب الحركة أو اختبار
هاتف فعلي. نتيجة اختبار Android وبصمة APK تسجلان في PROJECT_HISTORY_AR.md.
