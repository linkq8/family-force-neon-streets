# Family photo inputs

Add one folder per playable person, for example:

```text
photos/
  parent/
    01-front.jpg
    02-three-quarter-left.jpg
    03-three-quarter-right.jpg
    04-smiling.jpg
    05-full-body.jpg
  kid-1/
    front.jpg
  kid-2/
    front.jpg
  kid-3/
    front.jpg
```

Use 5–20 clear individual photos for each person; 8–12 varied photos produce
the most dependable Higgsfield Soul likeness. Include a straight-on face,
three-quarter views from both sides, a few expressions, and at least one
three-quarter or full-body image. Keep the eyes and face unobstructed. Avoid
group photos, sunglasses, beauty filters, and near-duplicate poses.

Also provide each person's display name, preferred outfit color, and one
recognizable accessory if desired. The originals stay in this local workspace
and are excluded from Git. When character generation runs, the selected images
are uploaded only to the authenticated Higgsfield account as visual references.
