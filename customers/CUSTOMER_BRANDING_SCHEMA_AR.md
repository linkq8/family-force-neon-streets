# تخصيص هوية المناسبة (المرحلة 8)

يدعم `customer.json` الآن كتلة `branding` اختيارية. غيابها لا يغيّر اللعبة الحالية؛
إذ تستخدم اللعبة قيم Family Force الافتراضية تلقائيًا.

```json
"branding": {
  "appDisplayName": "اسم التطبيق على الجهاز",
  "eventTitle": "عنوان المناسبة داخل اللعبة",
  "introMessage": "رسالة المقدمة",
  "outroMessage": "رسالة النهاية",
  "logoAsset": "ui/logo.png",
  "appIconRef": "default",
  "theme": {
    "primary": "#15D8FF",
    "accent": "#FF3DAE",
    "background": "#090B22",
    "text": "#FFFFFF"
  }
}
```

## العقد الآمن

- النصوص: 80 حرفًا للاسم والعنوان، و160 للمقدمة والنهاية.
- الألوان: `#RRGGBB` أو `#RRGGBBAA` فقط.
- `logoAsset`: مسار PNG أو WebP نسبي داخل assets؛ لا يسمح بمسار مطلق أو `..`.
- `appIconRef`: القيمة `default` تبقي الأيقونة الحالية. عند وضع مسار PNG/WebP
  مربع بدقة 512×512 أو أكبر داخل حزمة العميل، ينشئ مصنع APK تلقائيًا أحجام
  Android الخمسة وطبقة Adaptive Icon داخل موارد Release الخاصة بالطلب.
- `eventName` القديم ما زال مدعومًا ويصبح بديل `eventTitle` تلقائيًا.
- أي قيمة ناقصة أو غير سليمة تستبدل بقيمة افتراضية ولا تسبب crash.

هذه المرحلة لا تغيّر ملفات الشخصيات ولا الصور ولا الحركات.
