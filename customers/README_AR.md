# حزم عملاء Family Force

كل طلب مستقل داخل مجلد باسمه ويحتوي `customer.json`. لا يحتاج العميل إلى حساب أو
إنترنت؛ ملف الإعداد يُضمَّن داخل APK الموقّع.

للاحتفاظ برسومات اللعبة الأساسية، يكفي تعديل الأسماء في `customer.json`. لاستبدال
شخصية في طلب جديد، توضع الملفات التالية داخل مجلد `assets/heroes` الخاص بالطلب:

- `<assetStem>.png` — الوقفة الاحتياطية 256×384 RGBA.
- `<assetStem>_portrait.png` — الصورة الشخصية 256×256 RGBA.
- `<assetStem>_anim.png` — Atlas الحركات 1536×2112 RGBA، 8 أعمدة × 11 صفًا.

ترتيب صفوف الحركة ثابت: توقف، مشي، لكمة، ركلة، لكمة ثقيلة، ركلة ثقيلة، قفز،
ضربة خاصة، Link، إصابة، وسقوط. لا تُوضع الصور الأصلية أو صور العميل الخام داخل
مجلد `assets`؛ توضع فقط ملفات اللعبة النهائية ذات الخلفية الشفافة.

البناء:

```sh
cd android
./tools/build_customer_apk.sh ../customers/<order-id>
```

المخرجات تكون في `dist/customers/<order-id>/` وتشمل APK وتقرير التوقيع وبصمة
SHA-256 ونسخة من ملف تعريف الطلب.

## الطلبات التجارية الجديدة

ابدأ بنسخ مجلد `_template` إلى مجلد يحمل رقم الطلب نفسه، ثم عدّل
`customer.json`. المخطط الرسمي موجود في `schema/customer-order-v2.schema.json`.
القالب يبدأ بحالة موافقة `pending` عمدًا، ولا يجوز تغييرها إلى `granted` إلا بعد
وجود موافقة حقيقية قابلة للإثبات من الشخص البالغ أو ولي أمر الطفل.

فحص الطلب أثناء التحضير:

```sh
python3 android/tools/validate_customer_order.py customers/<order-id>
```

الفحص الصارم قبل التسليم:

```sh
python3 android/tools/validate_customer_order.py customers/<order-id> --delivery
```

الفحص الصارم يمنع التسليم إذا كانت الموافقة ناقصة، أو لم يُكشف عن استخدام الذكاء
الاصطناعي، أو انتهت مدة الاحتفاظ، أو نقصت الأصول، أو وُجدت صورة خام داخل أصول APK.
ملف الموافقة يسجل مرجع الدليل فقط؛ المستند أو المحادثة الأصلية تحفظ في نظام خاص
خارج مستودع الكود.
